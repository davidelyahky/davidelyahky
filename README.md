# Hey, I'm David 👋

I'm a **21-year-old electrical engineering student** who genuinely loves learning. About pretty much anything, but especially how things work and how I can use that to build things that actually matter.

### ⚡ What I'm about

I'm really passionate about **embedded systems**. There's something magical about writing code that lives on a tiny chip and makes the physical world *do things*. More than the tech itself though, I care about building projects that actually help people, and that's the part that makes it all worth it.

### 🔨 What I'm working on

Right now I'm building a **phone designed to help people overcome phone addiction**, a device that works *with* you instead of constantly pulling for your attention. It's equal parts hardware, firmware, and figuring things out as I go, and I'm loving the challenge.
